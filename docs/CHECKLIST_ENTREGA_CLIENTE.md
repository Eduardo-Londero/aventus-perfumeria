# Checklist de Entrega al Cliente — Aventus Perfumería

## Pre-entrega técnica
- [ ] `npm install` ejecutado.
- [ ] `npm test` en verde.
- [ ] `npm run lint` en verde.
- [ ] `npx tsc --noEmit` en verde.
- [ ] `npm run build` en verde.
- [ ] `npm run test:e2e` en verde (con credenciales de prueba).
- [ ] `.env.local` configurado por el cliente (no versionado).
- [ ] Sin secretos en el repositorio.

## Personalización
- [ ] Marca/logo aplicado.
- [ ] Textos institucionales revisados.
- [ ] Catálogo de prueba reemplazado o marcado como demo.
- [ ] Datos de contacto/WhatsApp/redes actualizados.
- [ ] Políticas de envío y devoluciones definidas.

## Producción (cuando el cliente lo autorice)
- [ ] Dominio y hosting configurados.
- [ ] Variables de entorno cargadas en el host.
- [ ] Smoke test post-deploy ejecutado.
- [ ] Supabase activado (si se contrata).
- [ ] Mercado Pago configurado (si se contrata).
- [ ] Email transaccional configurado (si se contrata).

## Documentación entregada
- [ ] README.
- [ ] `.env.example`.
- [ ] Guía de entrega.
- [ ] Guía de servicios externos.
- [ ] Alcance y funcionalidades.
- [ ] Presentación comercial.
- [ ] Paquete de venta.

## Verificación final
- [ ] Cliente puede distinguir demo vs producción.
- [ ] Cliente conoce limitaciones actuales.
- [ ] Cliente recibió listado de tareas pendientes de configuración.
- [ ] Capacitación básica del panel realizada.
