# Paquete de Venta — Aventus Perfumería

## Concepto

Aventus se comercializa como desarrollo web terminado para perfumerías, adaptable a cada negocio. El paquete incluye código, documentación y soporte de configuración inicial.

## Componentes del paquete

1. Código fuente completo.
2. Panel administrativo.
3. Documentación técnica y de entrega.
4. Pruebas automatizadas.
5. Guía de configuración de servicios.
6. Lista de tareas para producción.

## Entregables al concretar la venta

- Repositorio/código entregado.
- `.env.example` con variables requeridas.
- Guía de instalación y despliegue.
- Checklist de entrega.
- Capacitación básica del panel (opcional).

## Lo que no está incluido por defecto

- Costos de hosting, dominio, Supabase, Mercado Pago o email.
- Contenido, imágenes y datos del negocio.
- Diseño gráfico original (logo, fotografía profesional).
- Soporte ilimitado post-entrega (salvo acuerdo).

## Condiciones sugeridas

- Pago inicial para reserva/configuración.
- Pago final contra entrega y pruebas.
- Cambios de alcance cotizados por separado.
- Servicios externos a cargo del cliente.
